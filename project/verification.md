## 环境与方式
- Node.js 24.18.0；Playwright Chromium 153.0.8010.12；axe-core 浏览器扫描。
- 仅在 127.0.0.1 提供临时静态 HTTP 服务；另测 file:// 直接打开。
- 浏览器与检查工具独立于仓库，主页和仓库测试页不依赖它们。
- 中文截图环境使用本地 Noto Sans CJK SC；线上页面使用访客系统字体。
