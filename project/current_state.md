# 当前实现状态

## 页面
- 纯静态、面向客户的黑白商务 Portfolio；系统字体，首页无 CDN、API、分析追踪或游戏依赖。
- 首屏：个人定位、中航金网现职、20–30 人团队、项目及联系入口。
- 专长：业务建模、智能化实施、交付统筹；本体概念示意使用 HTML/CSS 绘制，不含客户架构。
- 实践：三个近期匿名案例，明确实施、前期实现及当前工作方向；六个原有历史案例使用原生 details 折叠，整体项目规模与个人职责分别表达。
- 经历：更新离职/入职时间、当前职务和管理范围；修正商飞经历误用零售职责。页面按月展示，中文完整履历保留日期。
- 保留教育、技术技能、方法、语言能力、四篇论文及完整作者、现有联系方式与 LinkedIn；增加 GitHub 入口。每篇论文附有 Google Scholar 完整标题检索链接，同步到完整履历。
- 原有水獭素材保留在仓库，当前页面使用姓名字母 LS 标识。

## 交互与兼容
- 中英日三语以静态属性存储；浏览器语言识别、手动选择持久化、存储不可用回退；标题、描述和导航标签随语言更新。
- 当前章节导航、原生锚点、键盘展开项目、跳过导航和可见焦点；移动导航留有锚点滚动空间。
- 无 JavaScript 可阅读中文、展开案例、联系；静态文件方式可直接运行。
- 桌面/移动端响应式；减少动态效果设置生效。
